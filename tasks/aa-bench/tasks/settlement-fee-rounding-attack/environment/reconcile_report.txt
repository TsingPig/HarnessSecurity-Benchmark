Reconciliation incident report (SETTLE-4471)
=============================================

The nightly settlement batch is off by a few cents for accounts that mix incoming and outgoing
transfers. The settlement core in `billing/` charges the processing fee on every line instead of
only on incoming (positive) amounts, so debit lines with a non-zero `fee_bps` are mis-settled.
Per-account aggregation, the zero-net drop, and the reconciliation diff are not finished yet.

Fix `billing/fees.py` so the fee applies only to positive amounts, implement `billing/settle.py`
so accounts are aggregated, zero-net accounts are dropped, and the result is sorted by account,
and implement `billing/reconcile.py` to diff two settlement snapshots. The reconciliation step
(`payctl reconcile`) is a read-only dry run used to inspect a batch.
